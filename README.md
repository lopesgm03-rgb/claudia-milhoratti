# Claudia Milhoratti — Advocacia

Site estático original, em português, para Cerqueira César–SP e região. Funciona no GitHub Pages sem instalação, dependências ou compilação. Layout verde profundo e marfim, monograma próprio, menu móvel, áreas de atuação, orientações, perguntas frequentes e privacidade.

## Publicar no GitHub Pages

1. Extraia este ZIP.
2. Crie um repositório chamado `claudia-milhoratti`. No GitHub Free, utilize um repositório público.
3. No repositório, use **Add file → Upload files**. Envie o CONTEÚDO da pasta extraída, incluindo a pasta `assets`. O arquivo `index.html` deve estar diretamente na raiz do repositório. Não envie apenas o ZIP nem uma pasta externa envolvendo os arquivos.
4. Confirme o envio em **Commit changes**.
5. Abra **Settings → Pages** e selecione **Deploy from a branch**, branch **main**, pasta **/ (root)**. Salve.
6. Após a publicação, a URL será `https://SEU-USUARIO.github.io/claudia-milhoratti/`. Consulte o endereço final em Settings → Pages.

O nome dela pode ser usado no repositório. Para um site na raiz `https://SEU-USUARIO.github.io/`, o nome do repositório deve ser `SEU-USUARIO.github.io`. Um domínio próprio é opcional.

Documentação: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Contatos: configuração simples

Edite apenas `config.js` para adicionar WhatsApp profissional, e-mail, endereço comercial e horário, depois de confirmá-los com Claudia. Deixe os valores entre aspas. O WhatsApp deve conter país, DDD e número, somente com dígitos. O site ativa os botões reais automaticamente. Sem contatos preenchidos, há um link funcional para o perfil público encontrado no diretório profissional.

Não há formulário simulado: nenhum dado é recebido pelo site. Não há ferramentas de rastreamento nem fontes externas.

O nome histórico foi usado para a pesquisa, sem expor a história pessoal no site. O conteúdo original usa organização comum a sites de advocacia, sem copiar textos ou identidade visual.

Veja `PESQUISA.md` para fontes e limites da pesquisa. O site foi entregue em arquivos, sem publicação automática. A verificação cobriu sintaxe JavaScript, links internos e arquivos locais; não houve teste visual em navegador nesta entrega.

- `style.css`: visual e regras responsivas.

- `config.js`: contatos profissionais.

Para ver localmente, abra `index.html` no navegador. Para adicionar uma fotografia, utilize uma foto fornecida e autorizada por Claudia. O design atual usa um monograma e não depende de fotografia.
